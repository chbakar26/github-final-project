# Simple Interest Calculator

A simple interest calculator that computes interest based on principal, rate, and time.

## Formula

**Simple Interest (SI) = (P × R × T) / 100**

Where:
- **P** = Principal amount
- **R** = Rate of interest (per annum)
- **T** = Time (in years)

## Example

- Principal = 1000
- Rate = 5%
- Time = 3 years
- SI = (1000 × 5 × 3) / 100 = **150**

## Usage

Input the principal, rate, and time to calculate the simple interest and total amount.
